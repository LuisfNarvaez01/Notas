# Hilva Implementation Plan

Goal: capturar offline y convertir apuntes contextualizados en prompts sincronizados entre Android y Windows.
Architecture: Flutter adaptativo, SQLite con registros versionados, servicios independientes de IA/nube/nativo.
Tech Stack: Flutter 3.47.7, Dart, SQLite, Supabase, Groq/Gemini.
Spec: docs/superpowers/specs/2026-11-20-hilva-design.md

## Global Constraints
Costo cero; uso personal; no emojis; claves fuera de código; guardado antes de IA; conservar originales; no fingir análisis de video.

## Review Focus
- Ediciones offline simultáneas: conservar ambas variantes.
- Respuesta IA inválida/429: no perder contenido ni reintentar indefinidamente.
- Reinicio y actualización: datos fuera de instalación.
- Adjuntos y exportación: conservar archivos y restaurar sin secretos.
- Layout móvil con teclado/texto grande: no overflow ni acciones ocultas.
