# Conectar Hilva 1.1

No hace falta Supabase ni Google Auth. Las configuraciones anteriores ya no se usan. No se han eliminado proyectos remotos.

1. Actualiza Android y Windows a 1.1.0.
2. Conecta ambos equipos a la misma red privada y abre Hilva.
3. Ajustes > Tus dispositivos > Mostrar QR en Windows.
4. Ajustes > Escanear QR en Android; el permiso de cámara se pide para escanear.
5. Espera el estado Sincronizado. Puedes usar Vincular con código si prefieres pegarlo.

El QR vence en 5 minutos y permite una vinculación. No lo compartas con terceros. Desvincular revoca la clave local; hazlo en ambos equipos si dejas de usarlos juntos.

Si no conecta: comprueba el firewall Windows, evita Wi-Fi de invitados con aislamiento, asegúrate de que Hilva esté abierta. Si cambia la IP vuelve a generar el QR. El PC puede usar Ethernet si está en la misma red del celular.

Las notas quedan locales cuando el otro dispositivo está apagado. En Android, abre Hilva para asegurar la sincronización; no se promete un servicio permanente en segundo plano.

## IA
Pega tus claves en Ajustes, elige un modelo disponible en tu cuenta y pulsa Probar conexión de Groq/Gemini. El botón prueba el valor escrito, aunque aún no lo hayas guardado. Pulsa Guardar configuración para conservarlo. Una prueba de cuota agotada no significa necesariamente una clave inválida. Ninguna clave se sincroniza.
